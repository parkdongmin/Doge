# Contract: 2부 화면

화면별로 무엇을 보여 주는지와 문구 초안을 정리한다. 세부 배치(위치·크기)는 스펙 Assumptions대로 구현 단계에서 시안을 보고 정한다. 모든 화면은 기존 게임 UI 규칙을 따른다: FacilityPanel/GameDialog/GameButton, 색 = 역할, 카드당 강조 버튼 최대 1개, 여러 줄 설명은 BodyReading 글꼴, ⓘ 문구는 해요체로 짧게.

## 1. 공용 컴포넌트

### `PlanetTraitRow` (특성 1개)

```text
[높은 생산력 Ⅲ]  적합도 높음
생산량이 많아요 · 생산량 +40%
```

- 1줄: 특성 이름 + 강도(좋은 특성만) + 적합도 글자("높음/보통/낮음"). 나쁜 특성은 적합도 자리에 아무것도 표시하지 않는다.
- 2줄: 쉬운 설명(3절) · 이 행성 기준 실제 숫자(4절).
- 색은 역할로만 나눈다. 좋은 특성은 기존 긍정색, 나쁜 특성은 기존 경고색을 쓴다. 금색은 쓰지 않는다(금색은 아껴 두는 강조색).

### `PlanetTraitList`

`PlanetTraitRow` 1~2개와 오른쪽 위 ⓘ로 이루어진다. ⓘ는 `InfoDialog`를 연다(5절 문구).

## 2. 화면별 표시

| 화면 | 표시 | 비고 |
|---|---|---|
| 발견 결과 창 (`DiscoveryRevealContent`) | 행성 정보 아래에 `PlanetTraitList`와 "특성 시세 +n%" (가격 줄 옆) | 리빌 연출이 끝난 뒤 나타난다. 특성 Ⅲ에 별도 연출을 더할지는 시안 단계에서 정한다(연출은 결정적 순간에만 쓰는 규칙) |
| 슬롯 가득 → 행성 바꾸기 창 (`SwapPickerDialog`) | 보유 행성 목록 줄마다 특성 이름 칩 | 무엇을 팔지 비교하는 화면이라 필요하다 |
| 행성 목록 (`PlanetScreen`) | 카드에 특성 이름 칩(최대 2개, 짧게) | 이름표에는 아이콘을 넣지 않는다 |
| 행성 상세 (`PlanetDetailScreen`) | `PlanetTraitList`. 악재 확률·드롭·강화 성공률 줄은 특성이 반영된 값을 보여 준다 | 기존 줄의 값만 바뀐다 |
| 탐사 팀 구성 시트 (`TeamBuilderContent`) | T1~T15 칩 항상 표시. 잠긴 다음 티어 칩에 조건 문구 (1부 미완주면 T11에 "1부 완주") | 기존 칩 디자인 그대로 |
| 탐사 화면 "다음 해제 목표" 배너 | T12~T15 조건과 진행도 (예: "특성 행성 7 / 10") | 기존 배너 재사용 |
| 탐사 일지 (`ExpeditionHistoryScreen`) | "1부 완주" / "2부 완주" 배지, 6~10장 "다음 이야기" 칸 | 기존 구성 재사용 |

## 3. 특성 쉬운 설명 — **초안, 사용자 확인 필요**

용어는 앱에 이미 있는 단어를 그대로 쓴다: 생산량, 악재/호재, 악재 확률, 고장, 자원 드롭량, 강화 성공률, 시세, 매도가, T11(티어 표기). "나쁜 소식", "코인을 만들어요", "항로"처럼 같은 뜻의 새 표현은 만들지 않는다.

특성의 Ⅰ·Ⅱ·Ⅲ은 플레이어 문구에서 **"등급"**이라고 부른다(2026-10-14 사용자 결정). 개발 문서의 "강도"와 같은 뜻이다. 화면에서는 `높은 생산력 Ⅲ`처럼 숫자만 붙이고, "등급"이라는 말은 ⓘ와 해금 조건에서만 쓴다.

해금 조건 문구 (탐사 배너·티어 칩):

| 티어 | 문구 |
|---|---|
| T11 | 1부 완주 |
| T12 | 특성 행성 10개 획득 |
| T13 | 적합도 높음 · Ⅱ등급 이상 특성 행성 2개 |
| T14 | 특성 행성 40개 획득 |
| T15 | 적합도 높음 · Ⅲ등급 특성 행성 2개 |

| 특성 | 한 줄 설명 |
|---|---|
| 높은 생산력 | 생산량이 많아요 |
| 낮은 생산력 | 생산량이 적어요 |
| 안정된 환경 | 악재 확률이 낮아요 |
| 불안정한 환경 | 악재 확률이 높아요 |
| 튼튼한 구조 | 큰 악재에도 잘 고장 나지 않아요 |
| 약한 구조 | 작은 악재에도 고장 나요 |
| 호황 체질 | 호재가 뜨면 생산량이 더 크게 올라요 |
| 풍부한 자원 | 자원 드롭량이 많아요 |
| 메마른 자원 | 자원 드롭량이 적어요 |
| 강화 적성 | 강화 성공률이 높아요 |
| 강화 부적성 | 강화 성공률이 낮아요 |

## 4. 실제 숫자 표기

| 축 | 표기 예 |
|---|---|
| 생산량 | `생산량 +40%` / `생산량 −10%` |
| 악재 확률 | `악재 확률 45% → 35%` |
| 고장 | `22% 이상 악재부터 고장 (기본 15%)` |
| 호황 | `호재 상승폭 +60%` |
| 자원 | `자원 드롭량 ×2.5` / `자원 드롭량 ×0.5` |
| 강화 | `강화 성공률 ×1.13` / `강화 성공률 ×0.95` |

## 5. ⓘ 설명 — **초안, 사용자 확인 필요**

> **특성**
> T11부터 찾은 행성엔 특성이 붙어요. 좋은 특성도, 나쁜 특성도 있어요.
>
> **적합도**
> 같은 특성이라도 행성마다 잘 맞는 정도가 달라요. 적합도가 높을수록 효과가 커요.
>
> **등급**
> 좋은 특성엔 Ⅰ·Ⅱ·Ⅲ 등급이 있어요. 등급이 높을수록 효과가 크고, 티어가 높을수록 잘 나와요.
>
> **시세**
> 특성 효과만큼 시세가 오르거나 내려요. 매도가에도 그대로 반영돼요.

이 아래에 이 행성에 붙은 특성의 정확한 수치를 4절 표기로 한 줄씩 나열한다.

## 6. 관제탑 2부 안내

- 기존 `TutorialOverlay`의 NPC 대화창에 story-content.md "관제탑 2부 안내" 5줄을 그대로 쓴다.
- 1~4줄은 대화만 보여 준다. 5줄에서는 첫 카테고리 카드(`EXPLORE_FIRST_CATEGORY`)에 스포트라이트를 둔다.
- 팀 구성 시트를 열면, T11을 아직 한 번도 성공하지 않은 동안 티어 줄을 T11까지 스크롤하고 T11 칩에 강조 테두리를 보여 준다(research R9).
