## 2. 해금 조건 (획득 기록 사다리, 매도해도 유지)

| 티어 | 조건 |
|---|---|
| T11 | 1부 완주 |
| T12 | 특성 행성 10개 획득 |
| T13 | "적합도 높음 + 강도 Ⅱ 이상" 좋은 특성이 붙은 행성 2개 획득 |
| T14 | 특성 행성 40개 획득 |
| T15 | "적합도 높음 + 강도 Ⅲ" 좋은 특성이 붙은 행성 2개 획득 |

"획득"은 1부 도감 등록과 같은 시점 — 구매, 또는 슬롯이 가득 찼을 때 "코인으로 받기" — 에 센다. 발견 창을 그냥 닫은 행성은 세지 않는다.
저장: 유저 정보에 누적 숫자 3개(특성 행성 획득 수 / 적합도 높음 Ⅱ+ 획득 수 / 적합도 높음 Ⅲ 획득 수). 도감은 기존처럼 변종 기준이며 특성과 무관.
진행 시뮬레이션은 발견 = 획득으로 가정했다(대부분 구매하거나 코인으로 받으므로 실제 차이는 작음).

## 4. 특성 효과 정의

| 특성 | 효과 축 | 적용 방식 |
|---|---|---|
| 높은 생산력 / 낮은 생산력 | 생산량 | 기본 생산량 × (1 + 값) |
| 안정된 환경 / 불안정한 환경 | 이벤트 악재 확률(eventRate) | 악재 확률 ± 값(%p) |
| 튼튼한 구조 / 약한 구조 | 고장 나는 악재폭 기준 (기본 15%p) | 기준 ± 값(%p) |
| 호황 체질 | 호재 시 생산 배율 상승폭 | 상승폭 × (1 + 값) |
| 풍부한 자원 / 메마른 자원 | 행성 자원 드롭량 | 드롭 기대값 × 배율 |
| 강화 적성 / 강화 부적성 | 행성 강화 성공률 | 성공률 × 배율 |

## 6. 특성 시세(가격)

- 특성 행성 가격 = 현행 발견 가격(basePrice + production×20 + risk×10) × (1 + 특성 시세 보정)
- 특성 시세 보정 = 붙은 특성들의 하루 순수익 효과(5절 표, 나쁜 특성은 4절의 행성별 값) 합. 강화 적성·부적성은 시도 증감율의 40%.
- 범위 대략 −25% ~ +75%. 구매가·매도가·시장가치(랭킹)에 그대로 반영.
- 예: 항성(211,140) + 높은 생산력 Ⅲ(높음, +35%) → 약 285,000.

## 8. 함께 바꾸는 경제 조정 (2026-10-13, 2부 행성 수집 대비)

2부에서 행성을 더 많이 모으고 키워야 해서 행성 관련 비용을 낮춘다. 이미 코드 반영·단위 테스트 통과(`ResourceCostTest`).

**행성 강화 자원 −10%** — 모든 레벨·등급에 일괄(`PLANET_UPGRADE_RESOURCE_DISCOUNT = 0.9`), 코인 비용 그대로.

| 강화 구간 (커먼) | 기존 | 변경 |
|---|---|---|

| Lv5~8 | 철광석 60, 크리스탈 25 | 54, 23 |

| Lv11~13 | 냉각재·마그마석 60, 바이오매스 40 | 54, 36 |
| Lv16~19 | 에너지 코어 80, 양자·데이터 코어 10, 미지 물질 8 | 72, 9, 7 |

**연구소 천체 분석(행성 슬롯) — 자원 −15%, 코인 +15%** (10-14: −20%에서 조정) — 천체 분석에만 적용, 다른 연구 3종은 그대로. 자원을 판매가 2배로 환산한 총비용은 레벨별 1~8% 저렴.

| 3→4 | 6,000 → 6,900 | 냉각재·철광석 200 → 170 | −4% |
| 6→7 | 22,000 → 25,300 | 생명 결정 300 → 255, 데이터 코어 200 → 170 | −4% |
