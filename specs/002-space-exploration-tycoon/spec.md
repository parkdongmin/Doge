# 게임 명세서: 우주 탐사 타이쿤

**작성일**: 2026-06-08 | **상태**: 설계 확정

---

## 게임 컨셉

플레이어가 **우주 탐사 회사**를 운영하는 타이쿤 게임.
우주인을 고용하고, 우주선을 구매·강화하고, 탐사팀을 꾸려 파견하여 행성과 자원을 발견한다.
발견한 행성은 코인을 생산하고, 획득한 자원으로 행성·우주선·연구소를 강화해 더 넓은 우주로 확장해 나간다.

### 핵심 루프

```
우주인 고용 + 우주선 구매
        ↓
  탐사팀 구성 + 카테고리 선택
        ↓
      탐사 파견
        ↓
  자원 획득 + 행성 발견 (확률)
        ↓
  행성 강화 → 코인 생산 증가
  우주선 강화 → 더 높은 티어 탐사
  연구소 강화 → 회사 확장
        ↓
    (반복 / 확장)
```

## 1. 행성 시스템

### 기본 개념
- 탐사 성공 시 행성이 **발견될 수도 있고 안 될 수도 있음** (확률 기반)
- 행성은 **코인만 생산** (자원 생산 없음)
- 손실 상태·유지비 시스템 **없음**

### 보유 한도
- 기본 최대 **10개**
- 연구소 천체 분석 분야 레벨업 시 **+1씩 확장**

### 행성 매도
- 매도 가격 = **매입가 + 강화에 투자한 코인·자원 환산액**
- 최대 보유 한도로 인해 더 좋은 행성 발견 시 기존 행성 매도 전략 발생

### 행성 강화 시스템
- 강화 재료: **코인 + 자원**
- 최대 레벨: **20**
- 강화 효과: 코인 생산량 증가

#### 강화 구간

| 구간 | 레벨 범위 | 실패 시 처리 |

## 2. 자원 시스템

### 기본 개념
- 자원은 **등급 없음**, 종류로만 구분
- 자원 보관 한도 **없음**
- 자원 획득처: **탐사 파견 결과**

### 자원 용도
| 용도 | 설명 |
|------|------|
| 행성 강화 | 강화 시도 시 코인과 함께 소모 |
| 우주선 강화 | 등급에 따라 필요 자원 종류 다름 |
| 연구소 업그레이드 | 각 분야 레벨업 시 자원 소모 |

### 탐사 카테고리와 자원 연결
- 탐사 카테고리에 따라 획득 자원 종류가 달라짐
- 팀 내 우주인의 전문 분야가 해당 카테고리와 일치하면 **보너스 자원 드랍** 가능

## 3. 우주인 시스템

### 획득 방식 — 모집 센터
- 모집 센터에 **후보 5명**이 노출되는 풀 형태
- **3시간마다 자동 새로고침** (전체 갱신)
- 후보를 영입하면 그 슬롯은 **비워진 채로 유지**됨 (다음 자동 새로고침 전까지 채워지지 않음)
- **광고 시청 시 즉시 전체 새로고침** 가능 (자동 새로고침 대기 없이)
- 훈련원 육성으로도 고급 우주인 확보 가능 (숙련도 성장, 아래 훈련 시스템 참고)

### 스탯 구조
- 우주인마다 **전문 분야** 보유 (광물·행성·유적·외계 문명 등)
- 우주인마다 **숙련도**(0~100) 보유 — 전문 분야 성과에 직결되는 핵심 스탯
- 우주인마다 **등급**(5단계) 보유 — 모집 시 확률적으로 결정되며, 숙련도의 시작값과 성장 한계(캡)를 결정

#### 등급 표

| 등급 | 출현 확률 | 시작 숙련도 | 숙련도 캡 | 고용 비용 배율 |
|------|-----------|-------------|-----------|----------------|
| 인턴 대원 | 65% | 10~25 | 50 | ×1.0 |
| 정규 대원 | 25% | 25~40 | 65 | ×1.5 |
| 수석 대원 | 6% | 40~55 | 80 | ×2.5 |
| 베테랑 대원 | 3% | 55~70 | 90 | ×4 |
| 레전드 대원 | 1% | 70~90 | 100 | ×8 |

- 등급은 숙련도의 **시작점과 상한선**만 결정하고, 실제 성장은 훈련으로 이루어짐
- 숙련도 100(최고치)은 **레전드 대원만 도달 가능** — 낮은 등급은 훈련해도 자기 등급의 캡을 넘지 못함

### 탐사 성과에 숙련도가 미치는 영향
- **탐사 성공률**: 파견 팀 내 해당 카테고리와 전문 분야가 일치하는 우주인들 중 **가장 높은 숙련도(MAX)** 값이 성공률 보너스를 결정 (같은 분야를 여러 명 데려가도 대표값 1개만 반영)
- **자원 획득량**: 파견 인원 전원이 기본 채집량에 기여하고, 그 위에 전문 분야가 일치하는 우주인들의 숙련도가 **합산**되어 추가 보너스로 적용 (매칭 인원이 많을수록, 숙련도가 높을수록 유리)

### 훈련 시스템
| 훈련 종류 | 비용 | 소요 시간 | 효과 |
|-----------|------|-----------|------|
| 기초 훈련 | 코인 | 4시간 | 숙련도 +5 |
| 심화 훈련 | 코인 + 자원 | 12시간 | 숙련도 +20 |

- 숙련도는 각 우주인의 **등급 캡**을 초과해서 오르지 않음 (캡 도달 시 추가 훈련 불가)
- 훈련 중인 우주인은 **탐사 파견 불가**
- 동시 훈련 가능 인원: 연구소 인사 관리 분야에서 확장

### 고용 한도
- 기본 한도 존재, 연구소 인사 관리 분야 레벨업으로 확장

## 4. 탐사 시스템

### 탐사 진행 방식
1. 탐사 카테고리 선택
2. 우주인 + 우주선으로 팀 구성
3. 파견 (소요 시간 대기)
4. 결과 수령

### 탐사 카테고리
연구소 탐사 기술 분야 레벨업으로 순차 해금

| 카테고리 | 해금 조건 | 주요 획득 자원 |
|----------|-----------|----------------|
| 광물 탐사 | 기본 해금 | 철광석, 실리카 등 |
| 행성 탐사 | 기본 해금 | 바이오매스, 결정체 등 |
| 유적 탐사 | 탐사 기술 Lv.3 | 고대 유물, 에너지 코어 등 |
| 외계 문명 탐사 | 탐사 기술 Lv.6 | 외계 기술, 미지의 물질 등 |

### 탐사 결과
| 결과 | 내용 |
|------|------|
| 성공 | 자원 획득 + 행성 발견 가능성 (확률) |
| 실패 | 아무것도 없음 (시간만 소모) |

### 탐사 지역 티어 (진행 구조)
| 티어 | 지역명 | 진입 조건 |
|------|--------|-----------|
| 1 | 태양계 | 시작 |
| 2 | 알파 성계 | 연구소 Lv.3 + 우주선 Lv.2 |
| 3 | 오리온 성운 | 연구소 Lv.5 + 우주선 Lv.4 |
| 4 | 은하 외곽 | 연구소 Lv.8 + 우주선 Lv.7 |
| 5 | 미지의 공간 | 최상위 조건 |

- 높은 티어일수록 희귀 행성 발견 확률 및 고급 자원 획득 가능

## 5. 우주선 시스템

### 기본 개념
- **다수 보유 가능 (함대)**, 탐사팀마다 다른 우주선 배정
- 보유 가능 수: 연구소 우주 공학 분야에서 확장

### 우주선 획득
| 방식 | 조건 |
|------|------|
| 코인 구매 | 기본 등급 우주선 |
| 코인 + 자원 제작 | 고급 등급 우주선 |

### 우주선 종류 (현재 → 미래)
| 종류 | 상태 | 특징 |
|------|------|------|
| 정찰선 | 현재 구현 | 균형형, 속도 강점 |
| 채굴선 | 미래 추가 | 적재량 최대, 탑승 인원 적음 |
| 연구선 | 미래 추가 | 탐사 성공률 높음, 행성 발견 확률 보너스 |

### 우주선 업그레이드 스탯
| 스탯 | 효과 |
|------|------|
| 탑승 인원 | 파견 가능한 우주인 수 증가 |
| 탐험 속도 | 탐사 소요 시간 단축 |
| 적재량 | 자원 획득량 증가 |
| 탐사 성공률 | 탐사 실패 확률 감소 |

## 6. 연구소 시스템

### 기본 개념
- **회사 확장의 허브** (직접적인 코인 생산 없음)
- 4개 분야로 나뉘며, 각 분야를 독립적으로 레벨업
- 레벨업 비용: 코인 + 자원

### 연구 분야

| 분야 | 레벨업 효과 |
|------|-------------|
| 탐사 기술 | 탐사 카테고리 순차 해금 |
| 천체 분석 | 희귀 행성 발견 확률 증가, 행성 보유 슬롯 +1 |
| 인사 관리 | 우주인 고용 한도 확장, 동시 훈련 가능 인원 확장 |
| 우주 공학 | 보유 우주선 수 확장, 신규 우주선 종류 해금 (미래) |

## 7. 회사 본부 (시설)

### 기본 개념
- **단일 허브 구조**, 목록 형태로 관리
- 시설을 건설·업그레이드하여 회사 기능 확장

### 주요 시설
| 시설 | 역할 |
|------|------|
| 연구소 | 4개 분야 연구, 회사 전반 확장 |
| 훈련 시설 | 우주인 기초·심화 훈련 |
| 격납고 | 우주선 보유·관리 |
| 모집 센터 | 주기적 우주인 모집 풀 갱신 |

## 미결 사항 (2026-07-08 기준 구현 현황)

| 항목 | 상태 | 내용 |
|------|------|------|
| 행성 희귀도 | ✅ 확정 | `RarityTier` 5단계(COMMON~LEGENDARY), 등급별 자원 드롭 배율 `GameConstants.RARITY_RESOURCE_MULTIPLIER`(1.0~3.2배), 탐사 티어 해금 조건도 희귀도 기준(`TIER_UNLOCK_CONDITIONS`) |
| 자원 종류 목록 | ✅ 확정 | `ResourceType` 14종 (광물 4·행성 4·유적 3·외계문명 3), 판매 단가는 `RESOURCE_SELL_PRICE` |
| 경제 밸런스 | ✅ 1차 확정 (튜닝 진행 중) | 행성/우주선/연구소 강화 비용 함수(`planetUpgradeCost`, `spaceshipUpgradeCost`, `researchUpgradeCost`)로 구현. 수치는 실플레이 피드백에 따라 계속 조정 예정 |
| 탐사 성공/실패 확률 | ✅ 1차 확정 (튜닝 진행 중) | 우주선 기본 성공률(70% + 등급당 +4%), 전문분야 일치 보너스(숙련도 기반)는 구현 완료. 행성 발견 확률은 기본 35% + 행성 카테고리 보너스(+10%) + 천체 분석 레벨당(+3%), 최대 80%로 코어스. 수치는 실플레이 피드백에 따라 계속 조정 예정 |
| 우주선 등급 수 | ✅ 확정 (2026-07-12) | 최대 6등급으로 캡(`GameConstants.MAX_SPACESHIP_GRADE`). `spaceship_2/4/6/8` 4단계 이미지에 맞춰 6등급에서 탑승 인원 8명(`MAX_CREW_CAPACITY`)에 도달하면 강화 종료. 그 시점 속도·적재량·성공률은 90/90/90% |
| 신규 우주인 모집 주기 | ✅ 확정 (2026-07-08) | 모집 센터 5슬롯, 3시간 자동 새로고침, 영입한 슬롯은 다음 새로고침까지 빈자리 유지, 광고 시청 시 즉시 새로고침(현재는 스텁 — 실제 광고 SDK 미연동). 우주인 등급 5단계(인턴~레전드)가 숙련도 시작값·캡을 결정 |
| 우주인 숙련도 시스템 | ✅ 확정 (2026-07-08) | 우주인 숙련도(0~100) 도입, 등급별 시작값·캡 상이. 탐사 성공률은 매칭 전문가 MAX 숙련도, 자원량은 매칭 전문가 숙련도 합산 보너스로 반영. 훈련(기초 +5/심화 +20)으로 숙련도 성장, 등급 캡 초과 불가 |
